# 蒸馏一课：指针与内存模型（C 语言核心第 1 课）

## 本课主题

C 语言的指针与内存模型：地址、指针、解引用，以及为什么数组传进函数就退化成指针。
重点是建立"内存是一段带地址的字节"这个心智模型，并讲清 `const` / `volatile` 的区别。

## 材料

通用权威资料：C 标准（C11/C17）6.3.2.1（地址与指针）、6.7.6（数组）、6.5.3.2（解引用）、
6.7.3（类型限定符）。参考教材：《C 和指针》（Ch 5-7）、《C 专家编程》（Ch 2）指针的错觉。
