# 租服务器与资源利用指南（CPU / 网络 / GPU 怎么分，怎么和 API + 本机资源配合）

> **调研时间**：2026-11-11。价格为公开区间，**波动大，以下单时官网实时报价为准**。
> 本文里的每条建议都针对**你本机的实际配置**（3060 12GB + 已有三个免费中转站 + 已跑的 DeepTutor）。

## 0. 先做一件事：算清你现在已经有什么

**你比大多数人富。** 别急着租，先把已有的用满：

| 已有资源 | 状态 | 能干什么 |
|---|---|---|
| **本机 RTX 3060 12GB** | ✅ 在（实测占用 2.4GB/12GB，util 15%） | 本地跑 qwen3:8b（DeepTutor 已接）；**Whisper large-v3 int8 也跑得动** |
| **本机 Ollama** | ✅ `qwen3` / `qwen2.5` / `bge-m3` / `nomic-embed-text` | 对话 + 嵌入，**免费离线** |
| **DeepTutor** | ✅ 跑着（3782） | 课程工作台、RAG、知识图谱、视频转写 |
| **中转站 ×2** | ✅ agentrouter + pincar | 免费额度，**两站每天签到 $25 + $20 左右** |
| **三台校内 GPU** | ✅ athena(3090×2) / atlas(5090+4090) / pollux(6000D×2, 85.6GB/卡) | **科研算力，不要拿来跑玩具** |
| **nginx/网络** | 有 frp 脚本、有 Cloudflare 账号 | 穿透 |

> ⚠️ **三台校内机是共享账号**（你的记忆里写了"三机多会话共用同一账号"），
> 而且 `ops\gpu-lease.ps1` 明确写着**只读别人的资源、不 kill、不改**。
> **不要拿它们当"免费云服务器"用** —— 那台机器在跑你的 RectSSL 科研。

**结论：**
- **要"网络/常驻服务"** → 租一台**便宜的 CPU 轻量服务器**（38~99 元/年）
- **要"临时大算力"** → 租**按小时 GPU**（0.4~2.5 元/时），用完立刻关机
- **要"日常学习/蒸馏"** → **本机 + 免费中转站**，一分钱不花

## 1. 三类服务器，别买混

| 类型 | 例子 | 典型价 | 适合你做什么 | **不适合** |
|---|---|---|---|---|
| **CPU 轻量** | 阿里云轻量 2核2G | **38 元/年**（秒杀）/ 68–79 日常价 / 99 续费同价 | **frp 服务端**、Cloudflare 回源、签到定时器、Jenkins、k3s、DNS | 跑模型、跑 GPU |
| **GPU 按量** | AutoDL / 智星云 / 恒源云 | **0.39~2.5 元/时**（4090），A100 3.5~4.5 | 一次性大模型推理/训练、Whisper large-v3 高精度转写 | 常驻服务（关机不付费，但排队+冷启动成本高） |
| **国际** | Vast.ai / RunPod | 4090 $0.55 / A100-40G $1.42 / H100 $2.80 每时 | 急用、要国际模型 | 国内访问慢、付款麻烦 |

> 💡 **云厂 GPU 贵 5~8 倍**：阿里/腾讯 A100-80G 约 **28~35 元/时**，
> 而 AutoDL A100-80G 约 **5~6.8 元/时**。**算力永远去 AutoDL 这类平台租，别在云厂买 GPU。**

## 2. CPU 轻量服务器：你真正该买的那台

### 2.1 价格横评（2026 公开区间）

| 厂商 | 配置 | 带宽 | 年付 | 续费 | 备注 |
|---|---|---|---|---|---|
| **京东云轻量** | 2核2G | 1M | **28 元/年** | — | 最低，但 1M 带宽很紧 |
| **阿里云轻量** | 2核2G 40G ESSD | **200M 峰值 + 不限流量** | **38 元/年**（秒杀，每日 10:00/15:00 两场） | 日常价 68~79 | **带宽最猛**，适合突发 |
| **腾讯云轻量** | 4核4G | 3M + 300GB/月 | **38 元/年**（秒杀） | 常规 79~99 | 配置最高 |
| 腾讯云轻量 | 2核2G 40G | 3M + 200GB/月 | 68 元/年 | 同价 | 稳妥 |
| **阿里云 ECS 经济型 e** | 2核2G 40G | 3M 固定 | **99 元/年** | **新老同价、续费同价** | ⭐ **长期最省心** |
| 华为云 Flexus L | 2核2G | 3M | 89 元/年起 | — | 部分机型另算 |

### 2.2 ⚠️ 三个决定性的坑（都来自实测/共识）

**① 首年低价 ≠ 长期便宜。**
秒杀款续费常回原价 —— 腾讯云某些套餐原价 780 元 → 活动价 109 元，**差近 7 倍**。
👉 **你要长期跑 frp，就买"续费同价"机型**（阿里云 99 元 e 实例 / 腾讯云 99 元轻量）。

**② 带宽策略完全不同。**

| | 阿里云 38 元款 | 腾讯云低价档 |
|---|---|---|
| 形态 | **峰值带宽 + 不限流量** | 固定带宽 + **月流量上限**（200–300GB） |
| 适合 | 突发访问、图片多 | 稳态小流量 |
| 超了 | 不限 | **降速** |

**3M 带宽实测约 375–384 KB/s** —— 只够个人博客、日 PV<3000、脚本测试。

**③ 国内节点要 ICP 备案（约 15–20 工作日）。**
香港/新加坡节点免备案但延迟高。
👉 **你有 frp 需求（国内访问要快）→ 买国内节点，但要提前备案。**
如果不想等备案 → **先买 38 元档做 Cloudflare Tunnel 的回源/备用**。

### 2.3 你的服务器要跑什么（按优先级）

```
① frps 服务端          ← 唯一必须的。ops\frps-install.sh 已备好
② frps 的 systemd 守护  ← 开机自启
③ 一个签到定时器       ← 7×24 跑签到（浏览器扩展做不到这件事）
④ 反向代理（Nginx/Caddy）← 证书 + WebSocket 透传（对应 REQ-NET-004/005）
⑤ （可选）Jenkins / k3s ← 原审计提到 "$5~8/月 绝不租 GPU"
```

**① + ④ 就够撑起"把 DeepTutor 安全暴露出去"这件事。**

### 2.4 买完之后的完整链路（和已有脚本对接）

```bash
# 【服务器上】
bash ops/frps-install.sh          # 装 frps，设 token，开 7000
# systemd 守护 + 开机自启

# 【本机】
# 编辑 ops/frpc-local.toml，填三处：
#   serverAddr = 服务器公网 IP
#   auth.token  = 与服务器 FRP_TOKEN 一致
#   customDomains = 你的域名
frpc.exe -c ops\frpc-local.toml
```

**别忘了这三步**（否则穿了也是裸奔）：
```
① DeepTutor 开认证 → 注册第一个账号（自动 admin）
② Nginx/Caddy 配 HTTPS 证书（Let's Encrypt 免费）
③ 反代开 WebSocket 透传（DeepTutor 聊天是流式 WS）
```

### 3.3 抢卡的真实痛点

- **4090 是各平台最难抢的卡**，高峰期「秒空」
- **A100 高峰排队 1~2 小时**，部分需预约
- 冷启动拉镜像 **30~60 秒**

**省钱的四个技巧**（都是平台共识）：
```
① 先开「无卡模式」把环境配好（约 0.1 元/时），再挂卡跑
② 设「定时关机」—— AutoDL 关机不付费（系统盘清空、云盘保留）
③ 选夜间/闲时段
④ 找支持原环境升降配的平台，配置不够直接升
```

> 💡 **AutoDL 计费按秒/分钟，关机不付费。** 这意味着
> **"需要时开机、用完就关"比包月划算得多** —— 包月 4090 约 700~1400 元，
> 而每天只用 2 小时 ≈ **150 元/月**。

### 3.4 你的场景到底该不该租 GPU？

| 任务 | 本机 3060 12GB 够吗 | 建议 |
|---|---|---|
| **Whisper large-v3 语音转写**（课程视频） | ✅ **够**（int8 量化，约 4~6GB） | **不租**，本机跑 |
| 蒸馏课程（LLM 蒸馏） | ✅ 12GB 跑 7B/8B 量化 | **不租**，用中转站额度 |
| RAG 向量化（bge-m3） | ✅ **本机已有** `bge-m3` | 不租 |
| 训 7B 以上 LoRA | ⚠️ 12GB 很紧 | 短期租 3090/4090 |
| 训 30B+ / 全参 | ❌ | 租 A100-80G |
| 科研大实验 | ❌ | **用你自己的三台校内机**（不是租） |

> ⚠️ **重要**：你的 RectSSL 科研**已经在用三台校内机**，
> 而且 `ops\gpu-lease.ps1` 是给那些机子用的**公共资源租约**机制。
> **不要为了"玩"去占用它们** —— 那是共享账号，你自己的实验在跑。

### 3.5 一个真实的省事组合

```
日常学习/蒸馏：  本机 DeepTutor + 本机 Ollama（免费离线）
              + 中转站额度（每天签到白嫖）        → 0 元

周末大任务：    AutoDL 无卡模式配环境 → 挂 4090 跑 4~6 小时 → 关机
              ≈ 1.6 × 6 = 10 元/次                    → 极低

网络常驻：      38~99 元/年的轻量服务器（一次性）      → 3~8 元/月
```

**合计 ≈ 一个月十几块。**

## 4. 怎么把「API + 本地资源」组合起来（这是重点）

### 4.1 四种组合，各管一段

| 组合 | 谁做什么 | 成本 | 适合 |
|---|---|---|---|
| **A. 中转站 API 全量** | 请求全走云端模型 | 额度/付费 | 要最好的模型效果 |
| **B. 本地模型全量** | 请求全走本机 Ollama | **0** | 隐私、离线、不想被打断 |
| **C. 本地做粗活 + 云端做细活** | 见 §4.2 | 极低 | ⭐ **推荐** |
| **D. 本地当调度器，云端当执行器** | 本机跑网关，按额度/健康度路由 | 额度/付费 | 你已有的 `dispatch.py` 就是雏形 |

### 4.2 ⭐ 组合 C 的具体切法（你的课程流水线）

```
                 ┌─────────────────────────────────────────┐
  百度网盘视频 ──┤ ffmpeg 切片(本地 CPU, 免费)              │
                 │   ↓                                     │
                 │ Whisper 转写 ──► 本机 3060 int8 (免费)   │  ← 粗活
                 │   ↓                                     │
                 │ .srt / .md 字幕文件                       │
                 │   ↓                                     │
                 │ 灌进 DeepTutor 知识库 ──► 向量化 bge-m3    │  ← 本机
                 │   ↓                                     │
                 │ 蒸馏出题/出讲义 ──► 中转站 gpt-6-astra    │  ← 细活
                 └─────────────────────────────────────────┘
```

**为什么这么切**：
- **粗活（转写、切片、向量化）= 纯算力，本机 3060 完全够，且完全免费**
  —— 把它扔到云上就是纯浪费钱。
- **细活（出题、讲义、答疑）= 需要好模型**，用中转站额度。

### 4.3 组合 D：你已经有雏形了

`技术蒸馏课程\99_工具与模板\dispatch.py` 就是一个**极简的调度器**：

```
按 (站, 模型) 顺序试 → 402 就换模型 → 429 就换站 → 找到能用的就发
```

**它已经实现了"额度感知路由"的核心**。要升级成完整的调度器，加三样：

| 想要的能力 | 怎么加 |
|---|---|
| **按任务类型选模型** | 简单题 → `gpt-6.1-sol`/便宜模型；蒸馏整课 → `gpt-6-astra`（共享模型，保持风格一致） |
| **本地兜底** | 前面加一个 `local-ollama` profile（provider 指向 `http://127.0.0.1:11434/v1`），额度全空时落到本机 qwen3:8b |
| **成本看板** | `.meta.json` 已经在记每次用哪个站/模型，汇总就是成本表 |

### 4.4 本地当调度器的一个硬约束（实测）

> ⚠️ **同机不能并发跑两个 `codex exec`** ——
> app-server 控制 socket 独占，第二个会挂：
> `failed to initialize in-process app-server client: access denied (os error 5)`
>
> **所以本地调度器必须串行。** 这也是为什么 `dispatch.py` 内部是顺序试而不是并发试。

### 4.5 穿透之后，本地和云怎么分工

```
外部用户 ──HTTPS──> 轻量服务器(Nginx+Caddy, 38元/年)
                         │  反代 + WebSocket 透传
                         ▼
                   frps ──frp 隧道──> 你家 DeepTutor (127.0.0.1:3782)
                                        │
                                        ├─ LLM 请求 ──> 中转站/云端模型
                                        └─ 转写/向量 ──> 本机 3060
```

**服务器只做"入口"，重活全在你家机器上** —— 这就是花 38 块/年买到
"外面能访问 + 国内速度快 + 数据不出门"的原因。

## 5. 花钱的优先级（按 ROI 排序）

| 优先级 | 花什么 | 多少钱 | 换回什么 |
|---|---|---|---|
| **1** | **什么都不花** —— 装 All API Hub 自动签到 | 0 元 | 两站额度每天自动到账（$45/天） |

| ❌ | **云厂 GPU** | 28~35 元/时 | **别买，贵 5~8 倍** |
| ❌ | **占用校内三台机** | 0 | **别占，科研在跑，且是共享账号** |

## 6. 立刻能做的四件事（不花钱）

```
① 装 All API Hub 扩展 → 两站每天自动签到（$45/天白白到账）

```
