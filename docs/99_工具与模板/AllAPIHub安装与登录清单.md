## 第 1 步 · ★★ 最关键的一步：先在浏览器里登录你的站

**这一步 90% 的人跳过，然后卡两小时。**

扩展是**借用你浏览器里已有的登录状态**干活的。你没在这个浏览器登录过这个站
→ 扩展没有登录状态可用 → 它以为你没注册过 → 添加失败 → 你以为是插件坏了。

**★ 一句话：先在浏览器登录，再回来装插件。**

现在就去 Chrome 里把下面「§3 登录 URL 清单」里的站**全部登录一遍**，
一个一个来，**每个站登录后确认页面上能看到余额/用户名**。

> ⚠️ **必须用 Chrome**。如果你用 Edge 登录的，扩展装在 Chrome 里就看不到。
> Edge 也行，但扩展要装在 Edge 里，**不能两边混**。

## 第 4 步 · 把站加进扩展

```
1. 点工具栏上刚装好的图标
2. 弹面板 → 找「添加账号 / Add Account」
3. 输入框填**站点网址**
   ⚠️ 只填域名，不要带 https://，也不要带后面的路径
   ✅ 对： api.你的站.com
   ❌ 错： https://api.你的站.com/dashboard
4. 点「自动识别 / Auto Detect」
5. 等几秒
```

**看到什么算成功**：列表里出现这个站，旁边显示余额。

### 自动识别失败？按顺序试这三招

```
第一招 ★ 回第 1 步，确认你在【同一个 Chrome 窗口】登录过这个站
第二招   把浏览器完全关掉重开，再登录一次，重试
第三招   确认网址只填了域名
```

## 第 5 步 · 打开自动签到

### 5.1 每个站的开关

```
账号列表 → 找到这个站 → 点右边的「⋯」或铅笔图标 → 编辑
→ 找「签到设置」→ 确认「启用每日自动签到」是【打开】的 → 保存
```

> **看不到这个开关 ≠ 你操作错了。**
> 说明**这个站没做签到功能**。这时候要么换一个支持签到的站，要么偶尔手动点一下。

### 5.2 全局设置（这一步决定你会不会被限流）

```
点扩展图标 → 设置 → 签到与兑换 → 自动签到
```

| 设置 | 改成 | 为什么 |
|---|---|---|
| **调度模式** | **「随机时间」**，不要「固定时间」 | 固定时间的话所有用这个插件的人都在同一秒打同一个站，服务器会卡，你也更容易被限流 |
| **时间窗开始/结束** | 你清醒的时段，如 09:00–22:00 | 不在你睡觉时乱跑 |

**改完点保存，立刻生效，不用重启浏览器。**

## 第 6 步 · 试跑一次（★ 别跳过）

```
1. 点扩展图标
2. 点「立即运行 / Run Now」
3. 等几秒到几十秒
4. 看结果
```

**成功**：显示"成功"或对勾，余额比刚才多了一点。

**失败原因对照表**：

| 你看到的 | 大白话 | 怎么办 |
|---|---|---|
| 401 / 未授权 | 登录失效了 | 回浏览器重新登录那个站，再重试 |
| 403 / 无权 | 账号信息对不上 | 扩展里删掉这个账号，重新添加 |
| 需要重新登录 | 同上 | 浏览器重新登录 |
| Cloudflare / 验证 | 网站有防护 | **等它自己重试**，扩展会切到浏览器方式处理 |
| Not Supported / 不支持 | 这站没签到功能 | 换站，或手动 |
| Needs Selection / 需选择 | 找到多个签到方式 | 手动选一个 |

**大多数失败会自己重试**（当天失败会再试几次，除非它判断"重试也没用"）。

## 你需要知道的三件事（都是真话，不是吓你）

### ① 浏览器关着，那天可能就不会签

扩展的定时任务依赖浏览器在运行。合盖睡了 → 那天不签。
**在意的话**看 `手把手文档集_v2_20261004\22_路线B_自建签到面板`（跑在服务器上，7×24），但复杂得多。

### ② 换电脑/换浏览器不会自动同步

数据存在**每个浏览器自己的存储**里。Chrome 的数据 Edge 看不到。
想多设备用要开 WebDAV 加密同步（需要自己有服务器，暂不建议折腾）。

### ③ 这个东西握着你的全部密钥

⚠️ 它要帮你签到，就必须持有你各个站的凭证。所以：
- ✅ 只从官方商店装（本文给的就是商店链接）
- ❌ 别装网上随便下的"绿色版""破解版"
- 装完去商店页面看看别人有没有大量投诉

> 🔒 **安全提醒**：这类扩展出过事 —— 赛门铁克调查发现大量 Chrome 扩展硬编码 API 密钥
> （影响 2000 万+ 用户）；Socket 披露过伪装成交易工具、偷取 MEXC API 密钥并回传
> Telegram 的恶意扩展（"MEXC API Automator"）。**认准上面那个官方 id。**
> 更详细的审查方法见 `手把手文档集_v2_20261004\24_扩展与脚本的安全审计_怎么验毒.md`。

## ⚠️ 最后一句要紧的

**装签到插件 ≠ Codex 能用上这些站的额度。**

- 签到插件解决的是「**额度每天到账**」
- Codex 用哪个站，是 `config.toml` 的 `model_provider` 决定的，**完全独立**

要让 Codex 真的用上新站的额度，得三步都做：
1. 把新站的 provider 块加进 `config.toml`
2. 给它加一个 profile
3. 把调度器的 SITES 列表加上它（`技术蒸馏课程\99_工具与模板\dispatch.py`）

**你开完新站告诉我，我把 2、3 步做掉。**
